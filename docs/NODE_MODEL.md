# 节点与通用素材工作流

Shape 的节点负责描述材料经过怎样的处理成为输出。AI 是执行方式，关系图用于组合与检查；
普通写作、生成和候选审阅可以直接在对应工作区完成。

| 节点 | 输入 | 输出 | 职责 |
| --- | --- | --- | --- |
| Source | 无 | 已保存的素材版本 | 只读提供原材料 |
| 文本创作 `text.create` | 无 | 独立文本 | 从需求、参考或手写开始 |
| 文本编辑 `text.edit` | 明确的已采用原稿 | 独立文本 | 改写、翻译、摘要、润色、扩写或编排文本，保留原稿 |
| 图片生成 `image.generate` | 无 | 图片候选 | 描述画面和画幅，审阅后明确采用 |
| 声音生成 `audio.generate` | 无 | 声音候选 | 描述音效或短音乐，试听后明确采用 |
| 素材处理 | 版本固定的图像或音频 | 派生候选 | 使用具体工具或外部编辑器处理副本 |
| Output | 对应步骤的结果 | 已采用版本 | 候选明确采用后才可作为下游正式材料 |

## 通用写作

新建写作进入统一文本工作区，可手写、让 AI 起稿或整理已有材料。
语气、读者与文风属于创作设置，个人预设的含义复制进当前配置，不依赖以后修改的个人库。

文本编辑创建独立输出，不替换原稿。原稿更新后，旧编辑仍固定引用旧版本；明确选择更新
输入后才切换来源。执行与采用再次检查原稿、输出和操作配置，过期候选不能越过这些检查。

普通文本与旧脚本格式由 `TextDocumentContract` 随不可变 Revision 保存。撤出配音制作界面
不会把旧脚本转换成普通文本、改写原字节或把旧配置拼进正文。旧格式可以作为文字继续编辑；
角色选声、演绎和合成在 Vox 完成。

## 身份与审阅

节点身份、输入绑定与配置属于可恢复的工作图。生成记录和已采用材料属于不可变历史。
反复运行和采用保留产出步骤的稳定身份，不能因当前选中行改变来源或结果目标。

候选留在临时审阅区，接受时由存储事务核验原稿版本、输出版本和确切操作。
旧的已采用版本仍可读。未执行草稿可以移除，已采用历史不能借“丢弃草稿”删除。

当前桌面按命名输出组织工作区。文本拓扑来自持久化输入绑定，部分图像工具仍投影已采用
历史。任意端口重连、多素材文本编译、可保存的任意画布布局和通用多输出组件仍有各自的
后续实现边界，不能用图上位置代替真实持久化关系。

## 旧专业节点

旧 `audio.speech_synthesize` 节点、卡组和绘本是兼容内容。它们显示来源、状态、材料与
专业应用继续入口，不再打开 Shape 内置制作工作台。旧脚本语法见 [格式说明](SPEECH_SCRIPT.md)，
迁移状态与原始材料保存见 [旧内容迁移](LEGACY_MIGRATION.md)。
