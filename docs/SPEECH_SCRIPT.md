# Shape 制作脚本规范

版本：`20260922.2`。配音脚本用于旁白、听力材料、多人对话及其他配音内容。脚本控制由 Shape 解析与执行，只有正文进入语音模型。

在文本工作区选择“配音脚本”，可直接写稿或让 AI 起稿、整理原文。角色、整体语气、提示音、停顿与重复都写在脚本中。
规则在输入正文前即可查看和复制。AI 候选稿与手写稿使用同一套格式校验；用户提出的制作要求由写作提示传达，不另设一份表单参数约束稿件。
文本节点保存制作意图；配音节点给角色绑定实际音色、给外部提示音绑定资源，并负责试听和 WAV 导出。

## 声音身份与一致性

- 角色代表实际说话者。独白通常一个角色；听力播音员、题目朗读者可以分开；真正的对话使用不同角色。
- 每个命名角色必须先声明，并在配音节点明确选定音色。未选定时阻止生成，不自动回退到工作区音色。
- 中英切换不创建角色，也不自动换音色。角色默认语言为 auto，支持混合语言。
- 整体朗读语气与文章文风分开。朗读语气作为独立指令发给模型，不作为正文朗读。
- 重复块只合成一次。后续播放逐样本复用第一次录音，包含块内对话、静音和提示音；不再次调用模型。
- 不同句子的自然语调仍须试听确认。固定音色及语气不是跨次生成的声学一致性保证。
- 一次生成固定源文稿、音色绑定与设置。修改配置或原稿后，旧候选不能被当作新结果采用。

## 声明区

声明必须在正文、片段及播放控制之前，每项只声明一次。参数用分号分隔，键值用冒号；支持半角或中文标点。
英文命令和值区分大小写，角色名与提示音名精确匹配。

```text
[production: listening]
[delivery: clear]
[role: Narrator; language: auto; description: 播报说明和题号]
[role: Reader; language: auto; description: 朗读题目正文]
[cue: answer; sound: beep; duration: 0.2s; level: soft]
```

| 英文指令 | 中文指令 | 值与含义 |
| --- | --- | --- |
| production | 用途 | listening / 听力、narration / 口播、dialogue / 对话；默认口播 |
| delivery | 整体语气 | neutral / 自然平稳、clear / 清晰平稳、warm / 温暖亲切、lively / 轻快活泼 |
| role | 定义角色 | 角色名；language / 语言（默认 auto）；delivery / 语气（可选，继承整体）；description / 说明（供选角参考，不朗读） |
| cue | 定义提示音 | 提示音名；sound / 声音：beep / 短音、chime / 叮咚、external / 文件 |

production 声明只标记用途，任何用途都可在角色声明中覆盖整体语气，或在正文中设置局部语气。
不要在角色名中加入题号，不要把语言当作人物身份。未声明角色的简单独白可以使用配音节点的默认音色。
如果文稿声明了角色，每段正文必须选定说话者。

Beep 可设置 duration / 时长（0.02–2 秒，默认 0.2s）及 level / 音量（soft / 轻柔、normal / 标准，默认 soft）。
内置短音和叮咚由 Shape 确定性生成，具有固定边缘渐变。同名提示音使用同一份定义。
external 必须在配音节点导入 WAV 或明确跳过；内置声音可以直接使用稿内定义，也可以显式更换。

## 正文与播放控制

| 中文 | 英文 | 行为 |
| --- | --- | --- |
| `[片段：第1题]` | `[scene: question-1]` | 开始一个制作单元；名称不朗读。清除上一片段的角色、语言覆盖和局部语气，重新选择角色。 |
| `[角色：Narrator]` | `[speaker: Narrator]` | 选择已经声明的角色，采用角色语言和语气；清除此前局部覆盖。 |
| `[语言：自动]` | `[language: auto]` | 覆盖当前角色的语言，直到切换角色或片段。 |
| `[重复：2次；间隔：2秒；提示音：turn]` | `[repeat: 2; gap: 2s; cue: turn]` | 开始重复块：总共播放 2 次；每两遍之间播放已声明的提示音，再额外静音 2 秒。`cue` 和 `gap` 都可省略。 |
| `[结束重复]` | `[end-repeat]` | 结束重复块。后续内容只播放一次，恢复进入块之前的角色和局部设置。 |
| `[停顿：5秒]` | `[pause: 5s]` | 在当前位置插入精确静音。 |
| `[提示音：answer]` | `[audio: answer]` | 顺序播放已声明的提示音。`音效`也是支持的中文名称。 |
| `[局部语气：温暖亲切]` | `[performance: warm]` | 临时调整当前角色的表现；`default` / `默认`恢复角色设置。 |
| `[备注：待教师审阅]` | `[note: Review with teacher]` | 不朗读、不影响执行的制作备注。 |

重复次数为 1–8 的整数，表示总次数；间隔为 0–120 秒，仅发生在相邻两遍之间。遍间提示音也仅发生在相邻两遍之间，最后一遍后不播放。提示音必须先声明；只播放 1 遍时不能指定遍间提示音。重复块不得嵌套，必须包含正文，片段不能放在块内。
普通停顿大于 0、至多 120 秒。所有时长最多三位小数，单位 s 或秒可省略。显式静音不随工作区语速变化。
语音本身可能包含句末静音；控制值表示额外静音，不承诺最后一个发音到下一个发音的声学间隔。

听力题如需题号、重复、提示音或答题时间，可按实际要求写在稿中。例如题号放在重复块外，题目正文放在块内，答题提示音和停顿放在块后。这是示例编排，不是格式强制规则。
若提示音只需出现在两遍之间，把提示音名写在重复指令的 `cue` 参数中；写在块内的 `[audio: turn]` 会随正文每遍播放，写在块后的提示音只播放在整个重复结束后。
所有角色与外部提示音必须在生成前明确绑定；多个角色选同一音色时会提示检查，允许用户有意复用。

## 听力示例

以下围栏只用于文档展示，复制稿子时不要复制围栏。

```text
[production: listening]
[delivery: clear]
[role: Narrator; language: auto]
[role: Reader; language: auto]
[cue: answer; sound: beep; duration: 0.2s; level: soft]
# 五年级英语听力
[speaker: Narrator]
听力测试现在开始。每小题读两遍。
[pause: 10s]
[scene: question-1]
[speaker: Narrator]
Number one.
[repeat: 2; gap: 2s]
[speaker: Reader]
Look at the boy. He is going to do tai chi in the park this Sunday.
[end-repeat]
[audio: answer]
[pause: 5s]
```

多人对话只需声明并绑定 A、B 两个角色，在同一个重复块里按顺序切换角色；完整对话的第二遍复用第一遍。
口播可以用 scene 安排章节、cue 标记转场、performance 调整局部语气，使用同一套格式。

## 排版与限制

普通非空行是正文；`# 标题`不朗读，空行不保证停顿。一行作为一个完整朗读段落，长段落按标点或词边界拆分。
粗体和行内反引号只去除标记；文字仍朗读。常见空格实体会还原。正文的字面方括号写作 `\[`、`\]`。
不使用代码围栏、表格、图片、HTML 或 Markdown 链接。未知指令、未声明名字、非法控制块均显示行号并阻止采用。

稿件最多 64 KiB、2048 个源事件，展开后最多 2560 个音频片段，最多 512 次实际语音请求。重复不会增加模型请求，但计入输出长度。
角色最多 32 个，提示音最多 128 个。WAV 导入要求 24 kHz、单声道、16 位 PCM，单个最多 8 MiB，总量最多 32 MiB。
导入文件保存到项目内，不依赖原路径。输出 WAV 最大 128 MiB。
音效当前按顺序播放，不与正文叠加；背景音乐、多轨混音和嵌套重复尚未开放。

AI 写作规则见 [SPEECH_SCRIPT_PROMPT.md](SPEECH_SCRIPT_PROMPT.md)。
