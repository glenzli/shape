# 创作能力与应用边界

Shape 保留通用 AI 素材创作、改写、处理、候选比较与版本；专业作品由各应用完成。
节点描述输入经过处理成为输出，关系图用于组合与检查，不要求每次创作都先画节点图。

## 各应用的责任

| 应用 | 负责的内容 |
| --- | --- |
| Shape | 通用文字、图像、声音素材的创作与转换；候选、来源、版本和处理组合 |
| [Deck](https://github.com/glenzli/deck) | 自由卡面、文字与素材、份数、版式、拼版及裁切线 |
| Storybook Co-Editor | 绘本脚本、页序、多语言、图文设计和出版 |
| [Vox](https://github.com/glenzli/vox) | 脚本驱动的配音制作、角色选声、演绎、录音版本与试听 |
| Shadow | 图片精修、调色和局部处理 |
| Echo | 专业声音编辑和混音 |

Shape 的新建入口围绕写作、图像、声音和素材导入。卡牌、绘本与配音制作在独立应用中继续。
应用可以独立工作，也能由人或 AI 通过具体能力接口串联；无需全部调用经过 Shape 桌面。
新的普通文稿或已保存写作草稿同样可以直接交给 Vox，不必先创建一个旧配音节点。

## 旧项目兼容

旧版 CardKit、PictureBook、配音脚本、工作草稿和已采用音频保留原有身份与字节。
兼容页只负责检查状态、查看绑定材料、选择快照和交接，不继续提供卡面制作、页序编辑、
打印排版或角色配音工作台。打开兼容页不能顺便保存、补默认值、创建版本或采用草稿。

- 卡组按明确选中的已采用版本或已保存草稿转入独立 Deck 工程，保留稳定卡 ID、隐藏字段、
  份数和精确材料。物料 ZIP 是交付物，不是完整工程迁移。
- 绘本按选中快照导出 Storybook 原生工程。未采用脚本与未完成状态必须保留，无法直接映射
  到原生工程的内容随交接保存并明确说明，不暗中采用或舍弃。
- 配音交接保存完整文稿、格式、写作草稿、角色选声、语言、语速、音效材料和可选已采用
  WAV。Vox 的新工程分别接纳已采用历史和未完成草稿；历史音频绑定它真正使用的旧文稿，
  不因当前稿已改写而改称新稿录音，也不宣称是 Vox 新合成。

原 Shape 工程不删除、不由另一应用打开后迁移。旧文本可以继续作为普通文字编辑，
原格式身份和精确字节不会因为专业工作台撤出而自动改变。迁移失败仍可回到原材料。

## 连续操作与具体适配

普通参数、预览和候选选择尽量留在当前工作区。需要专业制作时打开对应应用；
保存、取消、失败和实际输出分别表达。素材、来源版本和目标身份决定结果去向，
不能依赖当前选中行、当前窗口或进程退出码。

文档交接创建或打开专业工程，专业应用拥有其保存边界。素材转换固定输入版本、
请求和输出身份，得到可审阅结果后由所属应用明确使用。可后台执行的能力通过实际接口执行；
需要人编辑的步骤明确等待操作完成。缺少应用时应保留可用交接文件并说明继续方式。

各应用交换确定的素材副本、摘要、来源、目标与回执。迟到结果不能进入另一项目或卡位；
重复请求不能覆盖已经继续编辑的工程；取消与未知状态不能伪装成成功。外部编辑成功
只产生待审阅结果，不能静默替换已采用材料。

先维护 Deck、Vox、Shadow、Echo 和 Storybook 的具体适配。没有第二个真实消费者前，
不建立通用插件 SDK，也不把这些应用整套窗口嵌入 Shape。

## AI 与验收

每个应用公开真实操作、输入、目标身份、版本、缺项、执行状态和产物。CLI 与桌面
共用业务实现。AI 先观察，提交明确动作，再读回结果；可发现的能力本身不授予调用权限。
Shape CLI 对旧卡牌、绘本只暴露兼容读取与交接，专业制作由独立应用完成。

重点验证：

1. 新 Shape 界面和公开能力不再提供卡牌、绘本、配音制作工作台。
2. 旧工程的材料、历史和未完成草稿可读；检查与交接前后原内容不变。
3. Deck、Storybook、Vox 的实际消费者能读回迁移内容，草稿与已采用状态不混淆。
4. 重开、重复、过期、篡改和外部应用不可用时，状态明确、原材料完整。
5. 通用文字、图像、声音候选审阅，以及 Shadow/Echo 和 Deck 图片任务继续可用。

实际接口见相邻交接文档；源码、测试、打包产物和真实 Runtime 执行证据分别确认。
